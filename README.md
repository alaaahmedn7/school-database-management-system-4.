# School Database Management System

A school database project developed using SQL and Oracle Database during my first year of studying Information Technology.

## About the Project

This project was created as a university assignment during my first year while studying Database Fundamentals. It focuses on designing and managing a school database to organize students, teachers, classes, subjects, grades, and academic stages.

## Database Components

- Students
- Teachers
- Classes
- Subjects
- Grades
- Academic Stages
- Student Registration
- Teacher-Subject Relationships

## SQL Concepts Used

- CREATE TABLE
- INSERT
- UPDATE
- SELECT
- ORDER BY
- PRIMARY KEY
- FOREIGN KEY
- CHECK Constraints
- UNIQUE Constraints

## Technologies Used

- SQL
- Oracle Database

## Project Context

This was one of my first database projects during my first year as an Information Technology student, where I applied the database concepts I learned in practice.
